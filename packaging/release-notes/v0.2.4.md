# MyAIRAW 0.2.4

新增 MyAIRAW AI 助手：连接你填写的 OpenAI 兼容 API，按中文提示词生成照片显影调整，并保留完整撤销能力。

## New

- **AI 助手**：顶部进入「AI」，或从偏好设置打开 AI 页面。
- **模型配置**：填写 API 地址和 API Key，拉取模型列表并选择要使用的模型；配置只保存在本机。
- **权限控制**：可单独授权发送缩小后的当前照片预览，以及授权 AI 自动应用返回的显影参数。
- **可撤销调整**：AI 只允许返回曝光、对比度、高光、阴影、白平衡、色彩、清晰度和拉直等安全显影滑块，每次应用都是一条历史记录。

## Changed

- AI 请求在后台执行，不阻塞照片编辑界面。
- 照片预览不包含原始文件路径或 EXIF；原图不会被上传或覆盖。

## Limitations

- 当前 AI 只调整全局显影参数，不直接创建蒙版、修复点或文件操作。
- 需要用户自行提供可用的 OpenAI 兼容 API 地址、API Key 和模型权限；API 服务费用与可用性由服务提供方负责。

此包适用于 Apple Silicon、macOS 27.0 或更新系统。应用使用 ad-hoc 签名，尚未进行 Apple Developer ID 公证。

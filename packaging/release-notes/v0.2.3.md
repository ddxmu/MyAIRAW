# MyAIRAW 0.2.3

普通图片也可以调色和裁剪，并从 MyAIRAW 的专属 GitHub 仓库检查新版本。

## New

- **普通图片编辑**：JPG / JPEG、PNG、TIFF 可以进入显影，使用调色、曝光、裁剪和导出功能。编辑记录保存在图库，源图片不变，导出不能覆盖源图片。
- **增量更新**：优先使用匹配的签名文件级增量包，无适用包或校验失败时回退签名完整包；保留重启安装、启动确认、旧版本备份和失败回滚。

## Fixed

- **保持照片原来的亮度**：普通照片不再套用 RAW 的曝光曲线或默认锐化；支持 ICC 颜色转换和 EXIF 方向。

## Changed

- **独立更新来源**：偏好设置的更新接入 ddxmu/MyAIRAW 发布页。

首次请手动安装此版本，之后通过偏好设置 → 立即检查 / 更新至新版本更新。

此包适用于 Apple Silicon、macOS 27.0 或更新系统。应用使用 ad-hoc 签名，尚未进行 Apple Developer ID 公证。
PNG 透明区域在 RGB 编辑和导出时合成白色，原文件的透明通道保持不变。
